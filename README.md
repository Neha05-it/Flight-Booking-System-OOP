# ✈️ Flight Booking System

A Python-based Flight Booking System built using Object-Oriented Programming concepts.

## 🚀 Features

- View Available Flights
- Search Flight
- Book Flight
- View Bookings
- Cancel Booking
- Show Total Flights
- Show Total Bookings

## 🧠 OOP Concepts Covered

- Classes and Objects
- Constructors
- Instance Variables
- Instance Methods
- Class Variables
- Class Methods
- Static Methods
- Encapsulation
- Inheritance
- Method Overriding
- Polymorphism
- Abstraction
- Abstract Classes
- `@property`

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

Open the terminal in the project folder and run:

```bash
python flight_booking.py
```

## 🎯 Purpose

This project was created to practice and demonstrate Object-Oriented Programming concepts in Python through a real-world flight booking system.
